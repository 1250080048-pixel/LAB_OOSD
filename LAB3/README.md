- Môi trường / Version: Visual Studio 2022, .NET Framework 4.7.2, SQL Server, ADO.NET.

## Nội dung đã thực hiện
1. Khảo sát nghiệp vụ và xây dựng các biểu đồ UML (Use Class, Class, Sequence, State Machine, Activity).
2. Thiết kế Cơ sở dữ liệu SQL Server có khóa chính, khóa ngoại và các ràng buộc toàn vẹn (sức chứa, trùng lịch, thiết bị/ngày, cộng dồn dịch vụ, hóa đơn, thanh toán).
3. Phát triển ứng dụng WinForms theo mô hình phân tầng (UI - Service - Data) trên Visual Studio 2022.
4. Kiểm thử các quy tắc nghiệp vụ khắt khe của hệ thống.

## Hướng dẫn kiểm tra / chạy lại
- Bước 1: Chạy script SQL tại thư mục `Database/QuanLyKhachSan.sql` trên SQL Server để khởi tạo cơ sở dữ liệu và dữ liệu mẫu.
- Bước 2: Mở Solution `QuanLyKhachSan.sln` trong Visual Studio 2022.
- Bước 3: Cấu hình connection string trong `App.config` trỏ đến SQL Server của máy cá nhân.
- Bước 4: Nhấn `F5` (Start) để chạy ứng dụng WinForms.
